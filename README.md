# TECH WIX — Site

Site institucional da TECH WIX, criado em HTML, CSS e JavaScript e pronto para publicar no GitHub Pages.

## Antes de publicar

Abra `script.js` e altere:

```js
const WHATSAPP = "5598999999999";
```

para o WhatsApp real da loja, usando apenas números.

No `index.html`, altere também:
- WhatsApp
- Instagram
- Endereço
- Textos que desejar
- Produtos/serviços

## Publicar no GitHub Pages

1. Crie uma conta em https://github.com
2. Clique em **New repository**.
3. Nome sugerido: `tech-wix`
4. Deixe o repositório **Public**.
5. Crie o repositório.
6. Clique em **Add file → Upload files**.
7. Envie `index.html`, `style.css` e `script.js`.
8. Clique em **Commit changes**.
9. Entre em **Settings → Pages**.
10. Em **Build and deployment**, selecione **Deploy from a branch**.
11. Escolha a branch `main` e a pasta `/ (root)`.
12. Clique em **Save**.
13. Aguarde alguns minutos.

O endereço ficará parecido com:

https://SEUUSUARIO.github.io/tech-wix/
